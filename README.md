# 🌙 Night Drop - ناقل ملفات لاسلكي سريع

[![Python Version](https://img.shields.io/badge/Python-3.6%2B-blue?logo=python)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

خادم ويب صغير وأنيق، يمكنك من استقبال الملفات على جهاز الكمبيوتر مباشرة من أي جهاز في نفس الشبكة (هاتف، جهاز لوحي، كمبيوتر آخر) بكل سهولة وأمان.

### ✨ الميزات
*   **🚀 نقل فوري:** يعمل على شبكتك المحلية، بسرعات عالية.
*   **📁 رفع متعدد:** يمكنك رفع ملفات متعددة دفعة واحدة مع متابعة التقدم لكل ملف.
*   **📱 متجاوب:** واجهة مستخدم رسومية سهلة، تتكيف مع جميع أحجام الشاشات.
*   **🔧 لا حاجة لتثبيت:** يعتمد فقط على مكتبات Python القياسية، شغله واستخدمه.
*   **🎨 شكله حلو:** تصميم عصري مع وضعية الليل.

### 🛠️ متطلبات التشغيل
*   **Python 3.6** أو أحدث.
*   أي جهاز (مثل هاتفك أو حاسوبك) متصل بنفس شبكة الواي فاي.

2.  افتح الطرفية (Terminal) في مجلد الملف وشغّل السكربت:
